# ЭмИИн — личный ИИ-ассистент

ЭмИИн — это твой собственный ИИ-помощник, который работает в браузере на компьютере и на телефоне, как ChatGPT или Gemini. Внутри можно выбрать один из трёх движков: **Claude**, **Gemini** или **OpenAI**.

## Что умеет

- 💬 Диалог с историей — несколько чатов, всё сохраняется в браузере
- ⚡ Потоковые ответы — текст печатается по мере генерации
- 📝 Markdown: заголовки, списки, код с подсветкой и кнопкой «Копировать»
- 🖼️ Отправка картинок — ИИ распознаёт, что на фото
- 🎤 Голосовой ввод и 🔊 озвучка ответов
- 🌗 Тёмная и светлая тема
- 📱 Работает на телефоне, можно установить как приложение на главный экран
- ⚙️ Выбор движка и модели, системная инструкция, температура

## Что нужно для работы

1. **Node.js** версии 18 или новее → https://nodejs.org (кнопка LTS)
2. **API-ключ** хотя бы одного сервиса (как получить — ниже)

> Важно: сам «мозг» ИИ — это сервисы Anthropic / Google / OpenAI. Ключ даёт доступ к их ИИ. Ключ хранится на твоём компьютере в файле `.env` и никуда не отправляется, кроме API самого сервиса.

---

## Шаг 1. Получи API-ключ (есть бесплатные варианты)

### Google Gemini — проще всего и бесплатно (рекомендую для начала)

1. Зайди на https://aistudio.google.com/apikey и войди в Google-аккаунт.
2. Нажми **Create API key** (создать ключ), выбери проект, если попросит.
3. Скопируй строку ключа (начинается с `AIza...`).

### OpenAI (ChatGPT)

1. Зайди на https://platform.openai.com/api-keys и создай аккаунт.
2. Нажми **Create new secret key**, скопируй ключ (начинается с `sk-...`).
3. Для новых аккаунтов могут потребоваться стартовые кредиты/оплата.

### Anthropic (Claude)

1. Зайди на https://console.anthropic.com и создай аккаунт.
2. В разделе **API keys** нажми **Create key**, скопируй (начинается с `sk-ant-...`).
3. Новым аккаунтам обычно дают пробный баланс.

> 🔒 Ключ — это пароль от твоего аккаунта. Никому его не показывай и не выкладывай в интернет.

---

## Шаг 2. Вставь ключ в файл `.env`

Открой файл `.env` в папке проекта (правой кнопкой → «Открыть с помощью» → Блокнот) и вставь ключ напротив нужной строчки, **без кавычек и пробелов**:

```
ANTHROPIC_API_KEY=sk-ant-...      ← Claude
OPENAI_API_KEY=sk-...             ← OpenAI
GOOGLE_API_KEY=AIza...            ← Gemini
```

Достаточно одного ключа. Сохрани файл (Ctrl+S).

---

## Шаг 3. Запусти

**Способ А (проще всего, Windows):** дважды кликни файл `start.bat`. Он сам всё установит и откроет страницу.

**Способ Б (вручную):** открой PowerShell в этой папке и выполни:

```
npm install
npm start
```

Откроется страница **http://localhost:3000**

---

## Как открыть на телефоне

Пока компьютер и телефон в **одной Wi-Fi сети**:

1. Запусти ЭмИИн на компьютере (Шаг 3).
2. В чёрном окне сервера будет строка `На телефоне: http://192.168.x.x:3000`.
3. Введи этот адрес в браузере телефона.

Чтобы ЭмИИн стал «как приложение» на телефоне (Android, Chrome): меню ⋮ → **«Добавить на главный экран»**.

> Если хочешь пользоваться **из любого места** (не только дома по Wi-Fi) — выложи проект в интернет, см. следующий раздел.

## Размещение в интернете (бесплатно, доступ отовсюду)

### Render (https://render.com)

1. Зарегистрируйся → **New +** → **Web Service**, подключи папку/репозиторий с проектом.
2. **Build command:** `npm install` · **Start command:** `node server.js`
3. В разделе **Environment** добавь переменные `ANTHROPIC_API_KEY` / `OPENAI_API_KEY` / `GOOGLE_API_KEY`.
4. Нажми Deploy — получишь ссылку вида `https://твоё-имя.onrender.com`.

Аналогично работает **Railway** (https://railway.app). Сервер сам подхватывает порт из переменной `PORT`, которую задаёт хостинг.

## Настройки (кнопка ⚙)

| Настройка | Что делает |
|---|---|
| Движок ИИ | Claude / Gemini / OpenAI (активны только те, для которых есть ключ) |
| Модель | Выбрать из списка или ввести свою |
| Системная инструкция | Задаёт характер ЭмИИн |
| Температура | 0 = точные ответы, 2 = творческие |
| Макс. токенов | Длина ответа |
| Тема | Тёмная / светлая / авто |

---

## Если что-то не работает

| Ошибка | Что делать |
|---|---|
| «Ключ … не задан» | Проверь `.env`: ключ без кавычек и пробелов. Перезапусти сервер. |
| «Неверный API-ключ» | Скопируй ключ целиком ещё раз. |
| «Лимит запросов / квота» | Исчерпана бесплатная квота — подожди или пополни баланс. |
| Не открывается страница | Проверь, что Node установлен и окно сервера не закрыто. |
| Кнопка движка неактивна | Значит для него нет ключа в `.env`. |

## Структура проекта

- `server.js` — сервер: общается с API и отдаёт сайт
- `public/` — интерфейс (страница, стили, логика, иконка)
- `.env` — твои ключи (секрет, не выкладывай)
- `.env.example` — образец файла ключей
- `start.bat` — запуск в один клик на Windows
